# Adaptive Pergola 0.7.0

This stable release adds configurable shading margins and end-stop re-sync controls, and fixes the shutdown, tilt-stop, diagnostics, export and service-option issues found during beta testing.

## New since 0.6.2

- Configure projected shadow overlap (`lr_shade_margin_cm`, default **1.9 cm**) and additional past-axis shading safety (`lr_past_axis_safety_deg`, default **5°**). These margins can change the calculated shading angle; setting both to zero uses the bare grazing geometry.
- Trigger automatic end-stop re-sync by accumulated travel, movement count, or both, with configurable **AND/OR** combination.
- Choose the re-sync end stop: **nearest**, **closed**, or **open**, for automatic re-sync and the manual re-sync button.
- Complete the pergola-only runtime cleanup by removing the inherited non-pergola calculation engines and controls.

## Fixes since 0.7.0-beta1

- Disabling the integration or using emergency stop immediately blocks subsequent commands, including forced moves, and updates the enable switch. Switches and services share the same shutdown path.
- Stop commands use the supported primary axis, including `stop_cover_tilt` on tilt-only pergolas. Actuator errors are reported to the caller; emergency shutdown still attempts the remaining covers and leaves positioning disabled.
- Shutdown invalidates pending automatic and manual re-sync sequences, even if the integration is immediately re-enabled before a pending wait finishes.
- Roof sunlight diagnostics agree with the active solar calculation outside the inherited window field of view.
- `export_config` includes a `louvered_roof` section with effective geometry, tilt calibration, protected-area extensions and shading margins.
- `weather_enabled` and `cloudy_position` are available through `set_option` and the corresponding weather/light configuration services.
- Replace deprecated Home Assistant device-registry iteration with the supported lookup helpers.
- Clarify the existing climate policy and update-based manual-override expiration in the documentation.

## Validation

- **4,505 automated tests passed**, including 18 added regressions.
- **87 distinct live checks passed** against Home Assistant Core 2026.9.3 with a virtual pergola, covering service calls, priority handling, configuration flows, reloads, timers, re-sync and actual tilt-helper feedback.
- Ruff lint and formatting checks passed. Live validation used a virtual actuator; it does not verify physical motor behavior.

## Updating

Requires **Home Assistant 2026.4.0 or newer** and a pergola cover with tilt support. Update through HACS, then restart Home Assistant. The release asset is `adaptive_pergola.zip`.

This integration supports louvered-roof pergolas. Inherited non-pergola cover types are not supported by this release.
